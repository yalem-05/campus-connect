# 📚 School Management System (SMS)

A comprehensive, role-based School Management System built with modern web technologies. Streamline academic administration, student management, faculty coordination, and financial operations in one unified platform.

## 🌟 Features

### 🎯 Role-Based Access Control
- **Admin**: Full system control, user management, analytics
- **Faculty**: Course management, grade entry, attendance tracking
- **Student**: View courses, grades, attendance, payments
- **Staff**: Administrative tasks, fee collection, document management

### 📊 Core Modules
- **User Management**: Student, Faculty, Staff profiles with authentication
- **Academic Management**: Courses, departments, schedules, enrollment
- **Grade Management**: GPA calculation, transcripts, performance analytics
- **Attendance Tracking**: Real-time attendance, reports, alerts
- **Fee Management**: Payment collection, invoices, financial reports
- **Document Management**: Upload/download documents, certificates
- **Communication**: Announcements, notifications, messaging
- **Reports & Analytics**: Comprehensive reports with export options

### 🎨 Modern UI/UX
- Responsive design (Mobile, Tablet, Desktop)
- Dark/Light mode toggle
- Interactive dashboards with charts
- Real-time notifications
- Smooth animations and transitions

## 🛠️ Tech Stack

### Frontend
- **React 18** with TypeScript
- **Tailwind CSS** for styling
- **React Router v6** for navigation
- **React Query** for data fetching
- **Recharts** for data visualization
- **Axios** for API calls
- **React Hook Form** with Zod validation

### Backend
- **Node.js** with Express
- **PostgreSQL** database
- **Prisma ORM**
- **JWT** for authentication
- **Bcrypt** for password hashing
- **Express Validator** for input validation

### DevOps & Tools
- **Docker** for containerization
- **GitHub Actions** for CI/CD
- **ESLint** & **Prettier** for code quality
- **Husky** for git hooks

## 📋 Prerequisites

- Node.js (v18 or higher)
- PostgreSQL (v14 or higher)
- npm or yarn package manager
- Git
